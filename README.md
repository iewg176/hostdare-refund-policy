## 退款政策细则：哪些能退，哪些不能退

### 可以退款的部分

- **共享 cPanel / DirectAdmin 主机**：3 天退款保证。
- **VPS 服务**：3 天退款保证，需提供有效退款理由。
- 退款期限从你**首次购买**该产品的日期开始计算。

### 明确不可退款的项目

官方知识库里列得很清楚，下面这几类一律不退：

1. 域名注册（Domain registrations）
2. SSL 证书
3. 促销 / 折扣 VPS 套餐（Promotional/discounted VPS plans）——这点很重要，用了优惠码的订单通常不退
4. cPanel 或 CloudLinux 授权
5. 独立服务器（Dedicated server plans）
6. 价格低于 1 美元的产品
7. 通过 Bitcoin 或 WeChat Pay 支付的订单

### 退款时会被扣除什么

- 如果退款退到你的**原支付方式**，会扣 **1 美元手续费**。
- 如果退款退到你的 **HostDare 钱包余额**，则**没有手续费**。
- **续费服务一律不退款**——这点很多新手会踩坑，以为续费也能退，实际上不行。

### 退款可能被拒的几种情况

官方明确列了几条"可能拒退"的情形：

- 短时间内提交大量工单"刷"系统的；
- **当月已用掉分配带宽的 20% 或以上**的（即使是因为你自己的安全配置不当导致流量异常消耗也算）；
- 账户存在滥用行为的；
- 使用了促销 / 折扣码的订单。

## 退款怎么申请？一步步来

1. **登录客户中心**：进入 HostDare 的 billing 系统。
2. **提交 Support Ticket（工单）**：选择 Billing 部门，说明退款原因，要具体、合理——比如"线路到我所在地延迟过高""实际跑分与预期差距大"这种是合理理由，"我改变主意了"则大概率会被拒。
3. **等管理层审核**：退款理由是否"valid"由 HostDare 管理层判定。
4. **选择退款去向**：退到钱包免手续费，退到原支付方式扣 1 美元。
5. **注意带宽红线**：申请前先看一眼自己当月带宽用量，超过 20% 就别提了，提了也是被拒。

> 小提醒：工单尽量一次性把话说清楚，不要重复提交多条，否则可能被判定为"刷系统"直接拒退。
